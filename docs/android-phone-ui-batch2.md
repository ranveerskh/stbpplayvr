# Android phone UI batch 2 — test only

Base: verified stable v2.0.20, the performance batch, and the signed modern-theme test 2.0.20.2 (151a653). Branch: optimize/android-phone-ui-batch2. Version 2.0.20.3, same application ID, code 72 and existing signing certificate; no stable merge/tag/release.

Phones/tablets no longer scale buttons/cards on focus or press. The Quest device policy retains its existing focus scale and pointer handling. Phone Live row height changes from 78dp to 48dp, logo from 102x56dp to 52x32dp, spacing 8dp to 4dp. The focused Ivory Live surface uses pale gold rather than a fixed dark fill. TV rows, categories, navigation, preview/player code are unchanged.

Phone Movie grids offer 2/3/4 columns, remembered in new DataStore keys. Appearance offers Category dropdown position Top/Bottom (default Top), applied only to compact Live/Movies; Bottom places it above bottom navigation and opens the existing category dialog aligned at the bottom. Home has no category dropdown. No category search added; the full category list remains scrollable, opening near the selected item.

SearchSession is owned outside browser/details/playback composition and is reset when provider URL/MAC, parental mode or language changes. Clicking a result preserves its query, results, page, grid scroll and selected result focus. Returning to an already completed remote search reuses its result snapshot without another API request. Query edits invalidate that snapshot. Explicit Search Back still exits search. Search history is local per provider, separate from watch history/favourites, records submitted/selected queries, deduplicates case-insensitively and retains 25 recent terms. Its compact Clear removes only this history.

Validation: unit checks for phone/TV/Quest scale policy and search history behaviour; emulator UI checks for settings controls, 2/3/4 grid layout, category positioning, focused Ivory colour and 48dp row, unchanged focus dimensions, search browser disposal/return/focus/scroll/API count for movies and channel-type preservation, plus DataStore persistence and Clear isolation. Existing TV navigation/focus/Media3 fixture playback, phone keyboard/touch, and Quest layout/controller fixture checks rerun. API 30 emulator results are not physical TV/phone/Quest measurements. Release APK excludes test media and test-only screen capture code/permissions.
